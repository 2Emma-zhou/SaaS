Tier0 organizes data into a clear tree structure based on the UNS (Unified Namespace) concept. In this tree, each topic automatically generates an MQTT topic, making it easy to get real-time data.

## How to Build a Data Model
UNS defines a simple folder-file structure, based on which you can form the data hierarchy as a tree map.

### Building Models Manually
:::note
**factory/equipment/CNC** will be used as an example, in which `factory` and `equipment` are paths and `CNC` is a topic.
:::
1. Log in to Tier0, and then select **UNS**.
2. Select <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" /> > **New Path** to add a path (e.g. `factory`).

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/7.png" />

:::note
**Custom Attributes** are extra information of the path, you can addas needed, e.g. **Unit**.
:::

3. Select the path **equipment** under **factory**, and then click <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" /> > **New Topic** to add a topic (e.g.`CNC`) under it.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/8.png" />

4. Enter the information of the topic:

<ol>
<ol>
<li>Select <b>Type</b> among <b>State</b>, <b>Action</b>, or <b>Metric</b>.</li>
<li>Select whether to enable <b>Mock Data</b> and <b>Enable History</b>.</li>
<li>Click <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/9.png" /> and then add attributes to the topic.</li>
</ol>
</ol>

5. Click **Create**.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/10.png" />

### Importing Models
1. Log in to Tier0, and then select **UNS**.
2. Click <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/102.png" /> at the upper-left corner.
3. Import JSON to create models.
- Directly enter JSON.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/11.png" />

- Upload a JSON file that contains model information.
    1. Click **Download Template** and enter the model content according to template rules.

    <img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/13.png" />

    :::tip
    You can manually add a path and topic, click <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/103.png" /> to export it and use it as an example for import.

    <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/14.png" />

    :::
    2. Save the template file, switch to **File** tab on the **Import** window, and upload the file.

    <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/14-1.png" />

4. Click **Submit**.

## Optional Features
### Building Template
1. On the **UNS** page, switch **Namespace** to **Template** tab.
2. Click <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" />, and then enter the information of the template.
3. Click <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/9.png" />, select a topic under **Source**.
4. Click **Generate**, edit the attributes generated from the selected topic.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/15.png" />

5. Click **Create**.

### Creating Label
Labels are used for categorizing data models.
1. On the **UNS** page, switch **Namespace** to **Label** tab.
2. Click <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" />, and then enter the label name.
3. Click **Create**, and then click <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/16.png" /> to add topics under the label.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/17.png" />

4. Click **Create**.
