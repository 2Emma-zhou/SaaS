## How to Add Data Sources through Source Flow
Once the data model is built under **UNS**, you need to connect real data to the model for subsequent processing and use.

### Adding Data Flow Manually
1. Log in to Tier0, select **Flows**.

<img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/23.png" />

<table>
  <thead>
    <tr>
      <th>Index</th>
      <th>Item</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
  <tr>
      <td>1</td>
      <td>Flow Display</td>
      <td>Select to view all flows or only one category.</td>
    </tr>
    <tr>
      <td>2</td>
      <td>Flow List</td>
      <td>Displays flow information. Click the flow name to start editing the data flow.</td>
    </tr>
  <tr>
      <td rowspan="3">3</td>
      <td>Search/Filter</td>
      <td>Search for/filter existing data flows.</td>
    </tr>
    <tr>
      <td>New Folder</td>
      <td>Add folders to categorize data flows.</td>
    </tr>
    <tr>
      <td>New Flow</td>
      <td>Add new data flows.</td>
    </tr>
  </tbody>
</table>


2. Click **New Flow**, enter a name, select **Source Flow** as **Flow Type**, and click **Save**.
- **Source Flow**: Used to collect data from data sources and send it to UNS.
- **Event Flow**: Used to process data from UNS.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/24.png" />

3. Click the flow you just added, and drag in nodes according to your data source type (e.g.`modbus`).
4. Drag in an `mqtt out` node, and finish its configurations.

<ol>
<ol>
<li>
Add the internal broker via <code>emqx:1883</code>.
<img width={450} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/106.png" />
</li>
<li>
Set its subscription topic to the data model in <b>Namespace</b>.

For example, the data model structure is <code>factory/equipment/cnc</code>, the topic will be <code>factory/equipment/cnc</code>.
<img width={450} src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/107.png" />
</li>
</ol>
</ol>

5. Click **Deploy** at the upper-right corner, trigger the flow and the data will be sent to corresponding model under **Namespace**.

:::tip
You can save the the flow as different versions by clicking **Save Version**, and switch to the previous version when needed.
:::

### Configuring Data Source through Generated Flow
:::note
Data flow will only be automatically generated when you select **Use mock data** while creating topics.
:::
1. Log in to Tier0, go to **Flows** > **Source Flow**.
2. Find the flow with the same name as the created topic, and click to edit it.
3. Change the data source of the generated flow.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/72.png" />

4. Delete the **mock data** node and connect the source node to the rest of the flow.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/73.png" />

5. Click **Deploy** at the upper-right corner, and then trigger the flow.
6. Go back to **UNS**, check whether the data is received.

<img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/25.png" />
