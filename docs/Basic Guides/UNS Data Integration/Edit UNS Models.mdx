Tier0 enables model editing before import and after manual creation.

## Editing UNS Models before Import
1. Log in to Tier0, and then select **UNS**.
2. Click **Create Draft** at the upper-right corner, and then click **Import**.
3. Import models through JSON text or file, and then click **Save**.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/28.png" />

4. Select paths or topics of the imported models, edit on the right side, and then click **Save**.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/29.png" />

5. Click **Run Tests** to verify the model logic. If the test passes, click **Deploy**.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/30.png" />

6. Check the difference between the import model and the current deployed model, and then click **Confirm**.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/31.png" />

7. Go to the UNS homepage, select the imported model, check the changes you made.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/32.png" />

## Editing UNS Models after Manual Creation

1. Log in to Tier0, and then select **UNS**.
2. Click **Create Draft** at the upper-right corner, and then select an existing model.
3. Select paths or topics of the model, edit on the right side, and then click **Save**.

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/33.png" />

4. Click **Run Tests** to verify the model logic. If the test passes, click **Deploy**.
5. Check the difference between the edited model and the current deployed model, and then click **Confirm**.
6. Go to the UNS homepage, select the edited model, check the changes you made.

:::tip
You can also directly create models as drafts, run tests, make sure its logic is correct, and then deploy it.
:::
