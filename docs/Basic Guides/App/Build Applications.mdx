Tier0 enables you to build industrial applications simply by talking to an LLM in natural language, and manage them in one place.

## Building Applications
1. Log in to Tier0, and select **App** > **Projects**.
:::info
A starter project is available for you to experience the application building process.
:::
2. Click **Create Project**, enter the project name and description, select an industry and click **Create**.

    <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/75.png" />

3. Open the project, click **Create App**, and you will be redirected to the application building page.

    <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/113.png" />

4. Define the application through prompts, and start building it.
:::info
You can delete the sample prompts and enter your own.
:::
    1. Click **App Type**, select the type you want from the drop-down list.
        
        <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/76.png" />
    
    2. Click **Feature** to switch between all features, select the one you want.

        <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/77.png" />
    
    3. Click <img width={20} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/78.png" />.

:::info
 Click the project name at the lower-left corner of the dialog window to switch between projects, or create new projects.
:::

5. Wait for the building to complete, and check the application details.
:::tip
You can always change the application configurations by talking to the LLM while building.
:::
6. Fine-tune your application by talking to the LLM after the initial build.

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/117.png" />

:::info what else you can do about the application
- Click <img width={20} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/119.png" /> at the upper-right corner to download the installation package of the application.
- Click **Snapshot** at the upper-right corner to create a snapshot of the application, which can be used to restore the application to a previous state when needed.
:::

7. Click **Deploy** at the upper-right corner after preview the application, enter release notes and then click **Start Deploy**.

<img width={350} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/131.png" />

8. Go to **Projects**, the deployed application will be listed there, click the application to view the details.

:::warning
For **Snapshot** versions, click **Deploy** will restore the application to the state when the snapshot is created, so please be cautious when deploying.
:::

2. Click **Launch**, and you can see the application you just deployed.

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/122.png" />

:::info what else you can do
Click **Switch App**, you can select all launched applications to view.
:::

3. Go to **Launchpad**, select an application and use it.

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/123.png" />
