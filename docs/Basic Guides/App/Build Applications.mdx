## How to Build Applications through Natural Language
Tier0 enables you to build applications simply through talking with LLM in natural language, and manage them in one place.

1. Log in to Tier0, and select **App** > **Projects**.
2. Click **Create Project**, enter the project name and description, select industry and click **Create**.

    <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/75.png" />

3. Go to **Builder**, define your application, and start building.
    1. Click the **Type of App**, select the type you want from the drop-down list.
        
        <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/76.png" />
    
    2. Click **Feature** to switch between all features, select the one you want.

        <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/77.png" />
    
    3. Click <img width={20} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/78.png" /> to start building the application.

        <img width={650} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/79.png" />

 :::info
 - Click the project name at the lower-left corner of the dialog window to switch between projects, or create new projects.
 - Click **Build** at the lower-right corner to switch building mode between **Build** and **Design**.
    - **Build**: Data in the built application is connected to the Tier0 database.
    - **Design**: Data in the built application is stored in **LocalStorage** of the browser, which is for testing and preview.

<img width={450} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/80.png" />

:::

4. Fine-tune your application through talking to LLM after the initial build, and click **Deploy** at the upper-right corner to complete the application building.

<img width={450} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/81.png" />

5. Go to **Launchpad**, you can see the application you just deployed. Click the application to access it.
