## Using Notebook to Run SQL Queries

1. Log in to Tier0, and then select **Notebook**.

2. Enter the added notebook, and run the default cell to connect Tier0 namespace as data sources.

<img width={550} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/37-1.png" />

3. Add a cell, write `import marimo as mo`, and run it.

<img width={550} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/37-2.png" />

4. Find the table you need on the left, click <img src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/170.png" /> next to the table name to generate SQL statements automatically.

<img width={550} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/37-5.png" />

:::tip
- You can click <img src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/37-4.png" /> under **DATA SOURCES** on the left to add sources as needed.
- It can happen that certain packages are missing while connecting to some types of databases. In this case, click **Manage packages** on the left to install.
:::

5. (optional) Click **SQL** to add a new cell, and then select a connected database to run SQL statements.

## Using Notebook to Draw Charts
1. Log in to Tier0, and then select **Notebook**.
2. Create a new notebook, and then add the following 3 cells to draw a simple line chart.
- Cell 1: Import libraries
```python
import marimo as mo
```
- Cell 2: Query data from the database
```python
_df = mo.sql(
    f"""
    SELECT *
    FROM "table_name"
    LIMIT 100
    """,
    engine=tsdb_engine
)
data = _df
```

:::tip
Use a SQL cell to write queries and then click <img src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/171.png" /> on the cell end to switch the cell to Python. Make sure you assign the query result to a variable (e.g. `data`).
:::

- Cell 3: Draw a line chart
```python
import matplotlib.pyplot as plt

plt.figure(figsize=(10,5))
plt.plot(data["actual_runtime"])
plt.title("Actual Runtime")
plt.xlabel("Index")
plt.ylabel("actual_runtime")
plt.grid(True)
plt.show()
```
3. Click <img src="http://communityimage2.oss-cn-hangzhou.aliyuncs.com/172.png" /> at the lower-right corner to run all cells and view the chart.
