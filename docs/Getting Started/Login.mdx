

1. Access Tier0 with the given domain on a browser.
2. On the login page, click **Sign up here**.

:::tip
You can also use either Google or Github to automatically create an account.
:::

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/2.png" />

3. Fill in the required information, receive the verification code and go to the login page through the email.
4. Enter the registered email and password.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/1.png" />

5. Click **Login**.
6. Enter the invitation code to a workspace, or create a new one.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3.png" />

7. Click **Go**.
