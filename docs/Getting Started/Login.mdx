

1. Access Tier0 with the given domain in a browser.
2. On the login page, click **Sign up here**.

:::tip
You can also use either Google or Github account to quickly sign in.
:::

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/2.png" />

3. Fill in the required information, receive the verification code in your email and go to the login page.
4. Enter the registered username and password.

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/1.png" />

5. Click **Login**.
6. Enter the workspace.
    - Enter the invitation code to an existing workspace, and then click **Go**.

        <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3.png" />

        :::info
        The invitation code is only valid for 24 hours.
        :::

    - Click **Unlock Your 14-Day Free Trial** to apply for a new workspace.
        1. Enter the required information on the official site, and click **Send me the trial link**.

            <img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-1.png" />

        2. Click **Set Up Workspace** on the received approval email.

            <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-2.png" />
        
        3. Set the workspace name and click **Create Workspace**.

            <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-3.png" />


7. Wait for the workspace to be ready, you can start exploring the platform.

<img width={550} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-4.png" />

:::info important headsup
- Members of a workspace can only see **Launchpad** and use the applications inside.
- Admins of the workspace can see all features, but cannot delete the workspace.
- Owner of the workspace has all permissions, including deleting the workspace.
:::
