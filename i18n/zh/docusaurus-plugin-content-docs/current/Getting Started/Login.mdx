title: 登录
sidebar_label: 登录
---

1. 在浏览器中使用指定域名访问 Tier0。
2. 在登录页面，单击 **立即注册**。

:::tip
也可以使用 Google 或 Github 账号快速登录。
:::

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/2-1.png" />

3. 填写必填信息，接收邮箱验证码，然后进入登录页面。
4. 输入已注册的用户名和密码。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/1-1.png" />

5. 单击 **登录**。
6. 进入工作空间。
    - 输入已有工作空间的邀请码，然后单击 **确认**。

        <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-5.png" />

        :::info
        邀请码仅 24 小时内有效。
        :::

    - 单击 **创建工作空间** ，输入名称后单击 **创建**，创建新的个人工作空间。

        <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-6.png" />

    - 单击 **申请试用**，申请企业版工作空间试用。
        1. 在官网填写申请表，然后单击 **发我试用链接**。

            <img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-7.png" />

        2. 在收到的审批邮件中单击 **Set Up Workspace**。

            <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-2.png" />
        
        3. 设置工作空间名称，然后单击 **创建工作空间**。

            <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-8.png" />


7. 等待工作空间准备完成后，即可开始使用平台。

<img width={550} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/3-9.png" />
