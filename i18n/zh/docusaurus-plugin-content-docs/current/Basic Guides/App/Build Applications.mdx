Tier0 支持通过自然语言与大语言模型对话来构建工业应用，并在统一位置进行管理。

## 构建应用

1. 登录 Tier0，然后选择 **应用** > **项目**。

:::info
系统提供了一个入门项目，可通过该项目体验应用构建流程。
:::

2. 单击 **创建项目**，输入项目名称和说明，选择行业，然后单击 **创建**。

    <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/75-1.png" />

3. 打开项目，单击 **创建应用**，系统会跳转到应用构建页面。

    <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/113-1.png" />

4. 通过提示词定义应用，并开始构建。

:::info
你可以删除示例提示词，并输入自己的内容。
:::

    1. 单击 **应用类型**，从下拉列表中选择需要的类型。
        
        <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/76-1.png" />
    
    2. 单击 **功能** 在所有功能之间切换，并选择需要的功能。

        <img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/77-1.png" />
    
    3. 单击 <img width={20} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/78.png" />。

:::info
单击对话窗口左下角的项目名称，可以在项目之间切换，或创建新项目。
:::

5. 等待构建完成，并查看应用详情。

:::tip
在构建过程中，你可以随时通过与大语言模型对话来修改应用配置。
:::

6. 初始构建完成后，可以继续与大语言模型对话，对应用进行微调。

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/117-1.png" />

:::info 应用还支持以下操作
- 单击右上角的 <img width={20} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/119.png" />，下载应用安装包。
- 单击右上角的 **快照** 创建应用快照。需要时，可使用快照将应用恢复到之前的版本。
:::

7. 预览应用后，单击右上角的 **部署**，输入发布说明，然后单击 **开始部署**。

<img width={350} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/131-1.png" />

8. 进入 **项目**，已部署的应用会显示在项目中。单击应用可查看详情。

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/133-1.png" />

:::

2. 单击 **启动**，即可查看刚部署的应用。

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/122-1.png" />

:::info 你还可以执行以下操作
单击 **切换应用**，可以选择并查看所有已发布的应用。
:::

3. 进入 **应用中心**，选择并使用应用。

<img width={550} src="http://tier0saas1.oss-cn-hangzhou.aliyuncs.com/123-1.png" />
