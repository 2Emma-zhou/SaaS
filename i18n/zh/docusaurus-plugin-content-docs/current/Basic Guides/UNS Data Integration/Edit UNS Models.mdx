Tier0 支持在导入前以及手动创建后编辑模型。

## 导入前编辑 UNS 模型

1. 登录 Tier0，然后选择 **UNS**。
2. 单击左上角的 <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/104.png" />，然后单击 **导入**。
3. 通过 JSON 文本或文件导入模型，然后单击 **提交**。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/28-1.png" />

4. 选择已导入模型中的文件夹或文件，根据需要在右侧进行编辑，然后单击 **保存**。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/29-1.png" />

5. 单击 **运行测试** 验证模型逻辑。如果测试通过，单击 **部署**。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/30-1.png" />

6. 查看导入模型与当前已部署模型之间的差异，然后单击 **确认**。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/31-1.png" />

7. 返回 UNS 首页，选择已导入的模型，查看你所做的更改。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/32-1.png" />

## 手动创建后编辑 UNS 模型

1. 登录 Tier0，然后选择 **UNS**。
2. 单击左上角的 <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/104.png" />，然后选择一个已有模型。
3. 选择模型中的文件夹或文件，根据需要在右侧进行编辑，然后单击 **保存**。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/33-1.png" /> 

4. 单击 **运行测试** 验证模型逻辑。如果测试通过，单击 **部署**。
5. 查看原模型与当前模型之间的差异，然后单击 **确认**。
6. 返回 UNS 首页，选择已编辑的模型，查看你所做的更改。

:::tip
你也可以直接将模型创建为草稿，运行测试并确认模型逻辑正确后，再进行部署。
:::
