Tier0 基于 UNS（统一命名空间）理念，将数据组织成清晰的树状结构。在该结构中，每个主题都会自动生成一个 MQTT Topic，便于获取实时数据。

## 如何构建数据模型

UNS 定义了一种简单的文件夹-文件结构，你可以基于该结构对数据划分层级，并组织成树状图。

### 手动构建模型

:::note
本文以 **factory/equipment/CNC** 为例，其中 `factory` 和 `equipment` 是文件夹，`CNC` 是文件。
:::

1. 登录 Tier0，然后选择 **UNS**。
2. 选择 <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" /> > **新文件夹** 添加路径，例如 `factory`。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/7-1.png" />

:::note
**自定义属性** 是文件夹的补充信息，可按需添加，例如 **单位**。
:::

3. 在 **factory** 下选择文件夹 **equipment**，然后单击 <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" /> > **新文件**，在该文件夹下添加文件，例如 `CNC`。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/8-1.png" />

4. 输入文件信息：

<ol>
<ol>
<li>选择 <b>类型</b>，选项包括 <b>State</b>、<b>Action</b> 和 <b>Metric</b>。</li>
<li>选择是否启用 <b>模拟数据</b> 和 <b>启用历史记录</b>。</li>
<li>单击 <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/9.png" />，然后为文件添加属性。</li>
</ol>
</ol>

5. 单击 **创建**。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/10-1.png" />

### 导入模型

1. 登录 Tier0，然后选择 **UNS**。
2. 单击左上角的 <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/102.png" />。
3. 导入 JSON 创建模型。
- 直接输入 JSON。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/11-1.png" />

- 上传包含模型信息的 JSON 文件。
    1. 单击 **下载模板**，并按照模板规则填写模型内容。

    <img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/13.png" />

    :::tip
    你可以手动添加文件夹和文件，单击 <img width={20} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/103.png" /> 将其导出，并作为导入示例使用。

    <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/14-2.png" />

    :::
    2. 保存模板文件，切换到 **导入** 窗口中的 **文件** 页签，然后上传文件。

    <img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/14-3.png" />

4. 单击 **提交**。

## 可选功能

### 构建模板

1. 在 **UNS** 页面，将 **命名空间** 切换到 **模板** 页签。
2. 单击 <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" />，然后输入模板信息。
3. 单击 <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/9.png" />，在 **来源** 下选择一个文件。
4. 单击 **生成**，编辑根据所选文件生成的属性。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/15-1.png" />

5. 单击 **创建**。

### 创建标签

标签用于对数据模型进行分类。

1. 在 **UNS** 页面，将 **命名空间** 切换到 **标签** 页签。
2. 单击 <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/6.png" />，然后输入标签名称。
3. 单击 **创建**，然后单击 <img src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/16.png" /> 添加文件到标签下。

<img width={350} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/17-1.png" />

4. 单击 **创建**。
