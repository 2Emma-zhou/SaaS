## 用户旅程

按照图中所示顺序操作，即可在 Tier0 中完成你的第一个数据流。

<img width={450} src="https://tier0saas1.oss-cn-hangzhou.aliyuncs.com/53-1.png" />


- Tier0 采用文件夹-文件结构构建数据模型，便于追踪和理解；
- Tier0 通过 **数据连接** 从不同来源采集多种类型的数据；
- 采集到 Tier0 的数据可以在 **事件流程** 中进行多种方式的处理；

:::note
**数据连接** 和 **事件流程** 均基于 **Node-RED**。详细使用说明请参见 <a href="https://nodered.org/docs/tutorials/first-flow">Node-RED</a>。
:::
